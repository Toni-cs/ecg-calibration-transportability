## 4. 新攻击N1-N10终审裁决

### 4.1 逐条裁决

#### N1：纯统计贡献不被CBM接受 → **部分成立**

**成立的部分**：
- CBM确实是临床期刊，审稿人期望临床相关性
- "纯统计贡献"的措辞确实provocative，可能让CBM审稿人质疑临床相关性
- 审稿人可能质疑"如果贡献是纯统计的，为什么不投统计期刊？"

**不成立的部分**：
- CBM发表大量方法论论文，不要求所有论文都有直接临床应用
- "纯统计贡献"不等于"无临床相关性"——Brier reliability改善意味着模型置信度更接近真实频率，这间接影响临床决策可信度
- R4保留DCR/NCV作为secondary endpoints，并非完全放弃临床相关性

**终审裁决**：**部分成立——措辞问题，可修补。** 问题不在贡献本身（Brier reliability改善有间接临床意义），而在措辞——"纯统计贡献"过于绝对，应改为"校准方法论贡献（有间接临床意义）"。

**对接收概率的影响**：-1-3%（措辞调整后可缓解）

#### N3：Brier reliability理论先验是事后合理化 → **部分成立**

**成立的部分**：
- "TS不改变argmax → Brier reliability是自然主指标"的推理链有跳跃——其他指标（log loss、ECE）也不依赖argmax
- "自然主指标"措辞过强，暗示唯一合理选择
- 指标选择可能有事后成分

**不成立的部分**：
- TS不改变argmax确实是数学事实（先验的）
- **Brier reliability有比"不依赖argmax"更强的理论依据**：Brier = Reliability - Resolution + Uncertainty，TS只影响Reliability组件——这是更直接的理论依据
- R4隐含使用了Brier分解，但未明确论证

**终审裁决**：**部分成立——论证性问题，可修补。** R4应明确使用Brier分解论证（而非仅"不改变argmax"），并诚实承认指标选择有部分主观性。

**对接收概率的影响**：-1-2%（论证强化后可缓解）

**终审特别说明**：N3是R4新引入问题中**唯一不是纯措辞问题**的攻击——它涉及论证逻辑。但Brier分解提供了更强的理论依据，R5轮可以通过明确使用Brier分解论证来解决，不需要重新选择主指标。
