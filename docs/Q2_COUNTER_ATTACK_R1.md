## 致命攻击审查

### F1: 部分成立 — 数学事实正确，但致命性被夸大，可修补

#### 反方攻击的数学/逻辑：**正确**

反方的核心数学事实是正确的：**∀ T>0, argmax_i(logit_i / T) = argmax_i(logit_i)**。这是 Temperature Scaling 的定义性质，Guo et al. 2017 原文明确指出 TS "does not change the prediction"。因此，TS 永远不改变任何样本的 top-1 预测，top-1 误判率变化**精确等于0**。

这一数学事实无可辩驳。

#### 反方攻击的致命性：**严重（非致命）**

反方声称 F1 "摧毁整个临床意义论证主线"，这个评估**过于绝对**。原因如下：

**1. 正方E3描述中已经包含非argmax指标**

正方在 §2.2 E3 中明确写了三个指标：
- 误判率变化（false positive + false negative count）← 这个确实恒为0
- 预测为正类的样本数变化 ← 这个在阈值化决策下非0
- **临床决策改变率（argmax 不变但阈值化决策改变的样本比例）** ← 正方已经意识到argmax不变！

反方在攻击依据第2点也承认："E3 同时写'误判率变化'和'临床决策改变率（argmax 不变但阈值化决策改变）'。前者必然为0，后者才有意义。"

这说明正方**已经意识到了argmax不变**，只是H1假设的表述有误（把"误判率变化"作为主指标）。这是**表述错误**，不是**认知错误**。

**2. E3还有Brier分解这一独立指标**

E3计划做"Brier 分解：将 Brier score 分解为 reliability + resolution + uncertainty，TS 改善 reliability 的量级"。这个指标**完全独立于argmax**：
- Brier score = reliability - resolution + uncertainty
- TS 改善 reliability 分量（这是校准的本质）
- 即使argmax不变，reliability改善是可量化的临床价值

反方的攻击没有覆盖Brier分解这一指标。

**3. 备选叙事能存活，且不是"降级"**

反方说备选叙事"校准使置信度更可信"是"从临床决策影响降为置信度美学"。这个评估**过于苛刻**。

在临床实践中，**不确定性感知的工作流**（uncertainty-aware workflow）是真实存在的：
- 医生看到 P(AF)=0.85 vs P(AF)=0.62，对"高置信AF"和"低置信AF"的处理不同
- 人工复核阈值（如 P>0.7 自动报告，0.3<P<0.7 人工复核）依赖校准的置信度
- TS 使置信度更接近真实频率，对这类工作流有直接价值

这不是"置信度美学"，是**校准的临床落地方式之一**。CBM 审稿人（生物医学AI应用研究者）能接受这个叙事。

**4. F1摧毁的是H1假设的表述，不是整个E3实验**

F1真正摧毁的是：
- H1假设的表述"误判率变化 > 1%" ← 数学上不可能
- E3的"误判!率变化"指标 ← 恒为0

F1**没有摧毁**的是：
- E3的"阈值化决策改变率"指标 ← 非零，有临床意义
- E3的"Brier reliability分量"指标 ← 非零，有临床意义
- E3的"置信度校准改善"叙事 ← 备选叙事，能存活
- E2/E4/E5/E6等其他实验 ← 不受F1影响

#### 反方攻击本身的漏洞

**反方反攻击A的过度延伸**：反方说"TS是全局单一温度，在4类情况下，P(class_i) > threshold的决策改变方向取决于class_i的logit与其他类logit的相对位置，临床可解释性极差"。

这个攻击**部分正确但过度延伸**：
- TS确实是全局单一温度，这是TS的已知局限
- 但"临床可解释性极差"过于绝对——TS使所有类的置信度更接近真实频率，这个改善是**全局的**，不是"方向依赖"的
- 在二值化决策（如 P(AF)>0.5 判为AF）下，TS改变的是置信度的绝对值，不是相对排序——这个改变是可解释的

**反方反攻击B的合理点**：反方说"决策改变率本身不区分改对和改错——如果TS把50%的阈值化决策改了，但一半改对一半改错，净临床价值=0"。这个攻击**合理**，正方需要证明改对比例显著高于改错。

#### 修补方案（具体可操作）

1. **重写H1假设**（§8.2）：
   - 旧：`H1：ECE 0.016 的改善对应可感知的临床决策变化（误判率变化 > 1%）`
   - 新：`H1：ECE 0.016 的改善对应可感知的阈值化临床决策改变率 > 5%（在临床相关阈值 0.3/0.5/0.7 下），且改对比例显著高于改错比例（净临床价值 > 0）`
   - 可证伪条件：E3直接检验

2. **E3主指标重写**（§2.2 E3）：
   - 删除"误判率变化（false positive + false negative count）"作为主指标
   - 主指标改为：
     - **阈值化决策改变率**（在0.3/0.5/0.7阈值下，TS前后决策改变的样本比例）
     - **净临床价值**（改对比例 - 改错比例，需证明 > 0）
     - **Brier reliability分量改善**（TS改善reliability的量级）
   - 保留"临床决策改变率"作为辅助指标

3. **论文中主动声明TS性质**（§Methods新增）：
   ```latex
   \subsection{Properties of Temperature Scaling}
   Temperature Scaling is a monotone transformation of logits 
   (dividing by T>0 does not change the ordering). Therefore, 
   TS does not change top-1 predictions (argmax is invariant). 
   Its clinical value lies in: (1) threshold-based binary decisions 
   (e.g., P(AF)>0.5), where calibrated probabilities change the 
   decision; (2) uncertainty-aware workflows, where calibrated 
   confidence informs human review thresholds; (3) Brier 
   reliability improvement, which quantifies calibration quality 
   independent of argmax.
   ```
   这把F1从攻击点转化为**主动的诚实声明**。

4. **E3边际贡献调整**：从+8-10%降至+5-7%
   - 理由：阈值化决策改变率 + Brier reliability仍有临床价值，但弱于"误判率改善"叙事
   - 不是+3-5%（反方建议），因为阈值化决策和置信度校准在ECG临床工作流中确实有用

5. **多重比较校正**：E3在3个阈值（0.3/0.5/0.7）下计算决策改变率，需Bonferroni校正或报告所有阈值的结果（避免cherry-picking）

#### 修补后的影响

- E3实验仍然有价值，但主指标从"误判率变化"改为"阈值化决策改变率 + Brier reliability"
- E3边际贡献从+8-10%降至+5-7%（损失3%）
- H1假设重写，可证伪性更强
- 论文中主动声明TS性质，把攻击点转化为诚实声明
- **G1缺口（临床意义）仍然可以解决**，只是解决方案从"误判率"改为"阈值化决策 + 置信度校准"

### F2: 部分成立 — HARKing风险真实，但可规避为"开放科学叙事"

#### 反方攻击的数学/逻辑：**部分正确**

反方的核心逻辑是：把预注册失败（ID边界38.3% < 80%）重新包装为"发现"（1.9×比率是新发现），构成HARKing。

这个攻击**部分正确**：
- **正确部分**：从"失败"到"发现"的叙事转换确实有HARKing嫌疑。预注册的核心价值是confirmatory hypothesis testing，假设证伪就是证伪，不能事后重新解释为"发现"。
- **正确部分**：1.9×比率是post-hoc提取的，预注册时没有这个假设。
- **正确部分**：从"观察"到"发现"的升级，确实是HARKing的定义。

#### 反方攻击的致命性：**严重（非致命）**

反方声称F2"摧毁科学诚实性底线"，这个评估**过于绝对**。原因如下：

**1. 预注册的价值确实包括透明性，不只是confirmatory testing**

反方在反攻击A中说"如果预注册只是'透明性'，那任何事后重新解释都可以，预注册就退化为实验日志"。

这个论证**过于绝对**。预注册!的价值是多维的：
- **Confirmatory testing**：事先声明假设，事后承认结果（核心价值之一!）
- **透明性**：公开假设和分析计划，防止事后隐瞒不利结果
- **可重复性**：公开方法，便于复现
- **时间戳**：证明假设是在看数据前声明的

正方在 §4.2 Q9 回应"预注册的价值是透明性而非confirmatory声称"——这个表述**过于简化**，但不是完全错误。预注册的价值确实**包括**透明性，只是**不限于**透明性。

**2. 标记为exploratory是合理的科学实践，不是"装饰"**

反方说"如果所有假设都是exploratory，那预注册的统计效力为零"。

这个攻击**部分正确但过度延伸**：
- 如果所有假设都是exploratory，确实没有confirmatory声称的统计效力
- 但exploratory分析**本身是有价值的**——它是假设生成，不是假设检验
- 标记为exploratory是**诚实的科学实践**，比把post-hoc发现包装为confirmatory更诚实
- 预注册 + exploratory标记 = "我们事先声明了分析计划，结果与预期不符，我们诚实报告"——这是开放科学的核心实践

**3. "预注册反转为劣势"过于绝对**

反方说"预注册失败后重新解释为发现，这个优势反转为劣势——审稿人会认为'你预注册了又不当真'"。

这个攻击**只对C2重定位策略成立**，不对预注册本身成立：
- 如果正方**放弃C2重定位**，直接承认"预注册假设证伪"，预注册**仍然是优势**——它证明了正方诚实
- "预注册 + 诚实披露证伪"比"不预注册"更可信，因为前者证明假设是事先声明的
- 反方把"C2重定位策略的错误"等同于"预注册的反转"，这是**概念混淆**

**4. 1.9×比率可以作为descriptive statistics报告**

反方说"如果1.9×是descriptive，那它就不是'发现'，只是'观察'"。

这个攻击**正确**，但结论不是"1.9×不能报告"，而是"1.9×应该标记为descriptive observation"：
- Descriptive statistics在论文中是有价值的
- 只要明确标记"post-hoc exploratory observation, not confirmatory"
- 不做假设检验，只做descriptive报告
- 报告置信区间和跨方向稳定性

#### 反方攻击本身的漏洞

**反方反攻击A的滑坡谬误**：反方说"这比不预注册更糟糕，因为不预注册至少不会自相矛盾"。

这是**滑坡谬误**。预注册 + 诚实披露证伪 ≠ 自相矛盾。自相矛盾的是"预注册 + 事后重新解释为发现"，不是"预注册 + 诚实披露证伪"。正方只要放弃C2重定位，就不自相矛盾。

**反方反攻击B的合理点**：反方说"1.9×在不同方向间波动很大（很可能，因为4/6方向准确率<基线），这个'发现'就不成立"。这个攻击**合理**，正方需要报告1.9×的跨方向稳定性。

#### 修补方案（具体可操作）

1. **放弃C2重定位的"发现"叙事**（§3.2 C2）：
   - 旧叙事："从'ID边界失败'转为'ID-OOD收益结构发现'，1.9×比率是新发现"
   - 新叙事："预注册假设ID边界>80%未达到（实际38.3%），我们诚实报告这一confirmatory结果。1.9×比率是post-hoc exploratory observation，报告其点估计、置信区间和跨方向稳定性，不做假设检验。"

2. **重新定位预注册的价值**（§4.2 Q9回应重写）：
   - 旧："预注册的价值是透明性而非confirmatory声称"
   - 新："预注册的价值是多维的：(1) confirmatory假设检验——我们事先声明ID边界>80%假设，结果38.3%证伪，我们诚实报告；(2) 透明性——公开分析计划防止事后隐瞒；(3) 开放科学实践——预注册 + 诚实披露证伪本身就是贡献。"

3. **1.9×比率标记为exploratory**（§3.1叙事链条第5步重写）：
   - 旧："发现3：ID也有收益，OOD/ID ≈ 1.9×（C2，重新包装为'发现'而非'失败'）"
   - 新："观察3：ID也有收益（+0.0083），OOD/ID ≈ 1.9×（post-hoc exploratory observation，跨方向SD=X，不做假设检验）"

4. **C2叙事改为"开放科学"**（§3.2 C2升级重写）：
   - 核心贡献：首次以预注册方式证伪"TS在ID上有强边界"假设
   - 诚实披露：假设证伪 + 透明报告
   - 1.9×作为descriptive observation，附置信区间和稳定性分析

5. **C2边际贡献调整**：从+4-6%降至+2-4%
   - 理由："开放科学叙事"弱于"发现叙事"，但比"被攻击为HARKing"强

6. **补充E4分析**：用E4的温度分布分析，报告1.9×比率在6个方向上的分布（均值、SD、range），证明这个比率的稳定性或不稳定性

#### 修补后的影响

- C2从"发现"降级为"诚实披露证伪 + explor!! descriptive observation"
- 预注册从"被攻击为HARKing"转为"开放科学实践加分"

这个攻击**部分正确**：

- **正确部分**：2/6可部署方向上，用户怎么知道自己的迁移对属于可部署的2/6？正方没有提供部署前判据
- **正确部分**："需局部验证"确实有推卸责任嫌疑——LOCO是跨语料库泛化，不是单目标域部署决策

#### 反方攻击的致命性：**严重（非致命）**

反方声称F3"摧毁叙事重定位的核心卖点"，这个评估**过于绝对**。原因如下：

- 即使结论是"不适合"，用户避免了无效的校准尝试，**节省了时间和资源**
