#### 2.1.4 N1的严重性定性——终审独立判断

**反方定性**：致命（学术不端，可能直接拒稿）
**反反方定性**：成立但可修补（时间线管理失误，非故意欺骗）

**终审定性：严重可修补（介于"致命"和"成立但可修补"之间）**

理由：

**支持"严重可修补"（而非"致命不可修补"）的论据**：
1. **非故意欺骗**：A1修订案文件中明确写"待OSF时间戳存档"，说明作者知道还没有正式存档，没有刻意隐瞒。如果是故意欺骗，不会在文件中写"待存档"。
2. **方案文档错误，非论文已发表错误**：R2方案中的错误声明（"数据收集前已预注册"、"有OSF哈希存档"）是方案文档的错误，方案可以修改。论文尚未投稿，不存在已发表的错误声明。
3. **修补方案明确可行**：放弃"预注册"叙事，改用"诚实披露证伪"叙事。修补后C2仍有开放科学价值。
4. **CBM审稿人通常不深究OSF时间戳**：CBM（中科院二区）的审稿流程通常不包含对OSF预注册时间戳的深入核查。如果作者主动诚实披露时间线，风险可以规避。

**支持"严重"（而非"轻微"）的论据**：
1. **C2叙事的根基崩塌**：R2的C2贡献完全建立在"引用预注册协议A1.4.2规避HARKing"之上。如果A1.4.2的预注册性质不成立，C2退回到R1的状态（被F2攻击为HARKing）。这不是轻微问题。
2. **科学诚信风险**：如果在论文中声称"pre-registered before data collection"但实际不是，即使是无意的，一旦被审稿人发现，也会严重影响论文可信度。
3. **修补后价值降低**：从"预注册分支触发"退回到"诚实披露证伪"，C2的边际贡献从+4-6%降至+2-3%。

**终审结论**：N1是"严重可修补"问题，不是"致命不可修补"。但这是R2方案最严重的问题，必须在投稿前解决。

#### 2.1.5 N1的修补方案

**核心策略：放弃"预注册"叙事，改用"诚实披露证伪"叙事。**

具体修补步骤：

1. **立即将A1修订案正式存档到OSF**（即使时间戳已晚于实验，至少有正式存档记录）
2. **修改R2附录A**：
   - 删除"这一分支触发条件在数据收集前已预注册"
   - 删除"有OSF哈希存档，可验证预注册时间戳"
   - 改为诚实披露A1修订案的事后性质
3. **修改C2叙事**：从"预注册分支触发"改为"诚实披露证伪+post-hoc exploratory observation"
4. **在论文中透明披露时间线**：在Methods或Limitations部分写明实验和协议修订的时间线
5. **1.9×明确标记为post-hoc exploratory observation**

**修补后的C2叙事**：
> "We hypothesized that ID boundary condition satisfaction rate > 80%. The result (38.3%) falsified this hypothesis. We honestly report this falsification. The 1.9× OOD/ID ratio is a post-hoc exploratory observation with cross-direction stability analysis, not a confirmatory finding. Protocol amendment A1 (2026-09-05) was a post-hoc analysis plan based on partial experimental results, not a pre-registration. We transparently disclose this timeline."

**修补后影响**：
- C2从"预注册分支触发"退回到"诚实披露证伪"——仍有开放科学价值，但价值降低
- C2边际贡献从+4-6%降至+2-3%
- 接收概率影响：-7-12%（从35-45%降至28-38%）
- 规避了"学术不端"风险

### 2.2 效应量小（ECE 0.016）独立验证

**终审验证**：效应量小是无法修补的硬伤。

**独立分析**：
1. ECE 0.016意味着校准误差改善1.6个百分点，这在校准文献中属于较小效应
2. R2引入的Brier reliability改善也是0.01量级——换指标没有解决效应量小的问题
3. 阈值化决策改变率可能<5%（N8攻击），因为ECE 0.016对应的温度T可能接近1
4. 这是数据决定的硬约束，无法通过实验设计或叙事调整解决

**终审结论**：效应量小是硬伤，R2的诚实披露+多指标缓解是最佳策略，但无法消除这一硬伤。这一硬伤对接收概率的影响约-5-8%，已计入R2的估计中。

## Phase 5：最终裁决

### 5.1 裁决：GO WITH MODIFICATIONS（修改后继续）

### 5.2 裁决理由

**支持GO WITH MODIFICATIONS的论据**：

1. **N1可修补**：虽然N1是R2方案最严重的问题，但修补方案明确可行——放弃"预注册"叙事，改用"诚实披露证伪"叙事。修补后C2仍有开放科学价值，只是不能声称"预注册分支触发"。

2. **其他严重攻击都有具体修补方案**：
   - N2：放弃乘法模型，改用主观估计
   - N3：减少检验数量，预先声明主检验
   - N4：降级TS-DRA为"经验查表"
   - N5：诚实声明"2架构家族+1超参变体"
   - N6：降级"不确定性感知工作流"为"潜在应用"
   - N7：明确净临床价值定义
   - N8：降低H1阈值+准备备选叙事

3. **R2相比R1有实质改进**：E3主指标重写规避了F1攻击，C4定位调整规避了F3攻击，TS性质主动声明是正确策略。

4. **效应量硬伤无法修补但诚实披露**：ECE 0.016是数据决定的硬约束，R2的诚实披露+多指标缓解是最佳策略。

5. **9周时间线可行**：6个补充实验+论文重写，时间紧张但可行。

**反对REJECT的论据**：

1. **N1不是致命不可修补**：这是时间线管理失误，不是故意欺骗。方案文档的错误可以修改，论文尚未投稿。
2. **修补后方案有科学价值**：即使放弃"预注册"叙事，"诚实披露证伪+边界条件刻画+多指标校准评估"仍有CBM级别的科学价值。
3. **CBM审稿人通常不深究OSF时间戳**：如果作者主动诚实披露，风险可以规避。

**反对GO（直接进入实施）的论据**：

1. **N1必须在投稿前解决**：不能带着虚假的预注册声明进入实施阶段。
2. **其他严重攻击也需要修补**：N2-N8都有具体的修补方案，应在R3轮解决。
3. **R2轮未完全收敛**：反方和反反方对N1的严重性定性有分歧，需要R3轮验证修补后的方案。

### 5.3 裁决结论

**GO WITH MODIFICATIONS**：R2方案有科学价值，但存在1个严重可修补问题（N1预注册造假）和7个严重可修补问题（N2-N8），必须在R3轮修补后才能进入实施阶段。
