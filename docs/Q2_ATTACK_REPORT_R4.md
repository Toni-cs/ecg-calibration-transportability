## 1. R3 攻击规避验证（M1-M9 逐条验证）

### M1: 证伪语义陷阱——事后假设不能被"证伪"

- **R4 修补**：P1-3 将"falsified this hypothesis"改为"our post-hoc hypothesis was not supported by the complete data"
- **验证结果**：**规避成功**
- **理由**：
  1. R4 §4.2 C2 明确使用"our post-hoc hypothesis was not supported by the complete data"替代"falsified"
  2. R4 附录 A 进一步声明"We avoid the term 'falsified' because we did not have a priori hypothesis"
  3. 新措辞准确描述了事后假设不被数据支持的情况，不暗示 Popper 意义上的先验假设证伪
  4. 这是真正的语义修正，不是表面改词——R4 同时调整了 C2 的整个叙事框架（P1-4）
- **残余影响**：0%

### M2: "诚实披露证伪"作为贡献的循环论证

- **R4 修补**：P1-4 将 C2 从"诚实披露证伪"重新定位为"跨方向稳定性分析 + 时间线透明披露"
- **验证结果**：**部分规避**
- **理由**：
  1. **规避部分**：R4 确实不再把"诚实披露证伪"作为主要贡献，改为"跨方向稳定性分析"作为主贡献——这缓解了"诚实不是贡献"的循环论证
  2. **未规避部分**：
     - **"跨方向稳定性分析"只是描述性统计**：1.9× OOD/ID ratio 是一个描述性观察，不是实质性科学贡献。任何跨域研究都可以报告这种比率。"跨方向稳定性分析"作为主贡献，其科学价值存疑——它只是说"OOD 改善比 ID 改善大 1.9 倍"，这是一个观察结果，不是方法创新或理论发现
     - **"时间线透明披露"仍然是诚实，不是贡献**：R4 把"时间线透明披露"作为 C2 的次贡献，但这仍然只是披露研究过程，不是研究本身的科学贡献。M2 的核心攻击"诚实不是贡献"对"时间线透明披露"仍然成立
  3. **审稿人视角**："你的 C2 主贡献是'跨方向稳定性分析'——这只是报告了一个 1.9× 比率。次贡献是'时间线透明披露'——这只是诚实。这两个加起来构成 CBM 二区的贡献吗？"
- **残余影响**：-1-2%（"跨方向稳定性分析"作为描述性统计，贡献强度有限；"时间线透明披露"仍只是诚实）

### M3: EBT-LT 经验查表的循环依赖——"部署前查表"需要目标域数据

- **R4 修补**：P1-5 明确 EBT-LT 只需要少量未标注目标域数据，不需要标注数据
- **验证结果**：**部分规避**
- **理由**：
  1. **规避部分**：R4 §4.2 C4 明确声明"少量未标注目标域数据（用于估计源/目标先验距离、logit 分布距离）——不需要标注目标域数据"。这澄清了未标注 vs 标注的区别
  2. **未规避部分**：
     - **循环依赖的本质未消除**：即使只需要未标注目标域数据，用户仍需要已有目标域数据才能查表。如果用户已有未标注目标域数据，为什么不直接用 TS 在目标域上校准（TS 不需要标签，只需要 logits）？EBT-LT 的"部署前查表"价值仍然存疑
     - **TS 的特性使循环依赖更严重**：TS 只需要一个温度参数 T，在源域校准集上拟合。如果用户有未标注目标域数据，可以直接在目标域上评估校准效果（计算 ECE/Brier reliability 不需要标签——只需要预测概率和真实标签，但 ECE 的分箱评估确实需要标签...）。实际上，ECE 和 Brier reliability 的计算需要真实标签，所以"未标注目标域数据"无法直接评估校准效果——这进一步质疑 EBT-LT 的实用性
     - **审稿人视角**："EBT-LT 需要未标注目标域数据来估计先验距离和 logit 分布距离。但校准评估（ECE、Brier reliability）需要标签。所以用户有未标注数据但没有标签——EBT-LT 能提供什么有价值的预测？"
  3. **R4 的明确使用场景声明有帮助但不充分**：R4 声明"从业者已有少量未标注目标域数据，但没有标注数据"——但在这个场景下，EBT-LT 能提供的只是"经验性参考建议"，其预测能力有限
- **残余影响**：-1-2%（循环依赖的本质未消除，但澄清未标注 vs 标注有帮助）

### M4: 核心贡献聚焦到"阈值化决策"——ECG 4 类分类中不常见的场景

- **R4 修补**：P0-1 将核心贡献从"阈值化决策价值"重新定位为"Brier reliability 改善作为纯统计贡献"
- **验证结果**：**规避成功**
- **理由**：
  1. R4 §1 明确将核心贡献定位为"Brier reliability 改善（纯统计贡献，不依赖特定临床场景）"
  2. 阈值化决策降为辅助贡献，明确适用场景（多标签、二分类、辅助决策）
  3. Brier reliability 是纯统计指标，不需要特定临床工作流支撑——这确实规避了 M4 的"核心贡献聚焦到不常见场景"攻击
  4. **但引入新攻击 N1**：见 §3 新发现攻击
- **残余影响**：0%（M4 本身被规避，但引入 N1）

### M5: H1 阈值降低到几乎必然成立的水平——Cohen's d > 0.2 是"small effect"下界

- **R4 修补**：P1-6 多指标报告，不依赖单一阈值 d>0.2
- **验证结果**：**部分规避**
- **理由**：
  1. **规避部分**：R4 §3.2 E3 明确声明"不依赖单一阈值 d>0.2，让审稿人自行判断临床意义"，同时报告 Cohen's d 点估计 + 95% CI + NCV + DCR 绝对值
  2. **未规避部分**：
     - **效应量小的硬伤未消除**：ECE 0.016 对应的 Brier reliability 改善是 0.01 量级。无论报告多少指标，效应量小的事实不变
     - **多指标报告可能被质疑为"指标购物"**：当主指标（Cohen's d）效应量小时，增加多个辅助指标（NCV、DCR、ECE）可能被审稿人视为"寻找某个显著的指标"——这是另一种形式的 cherry-picking
     - **审稿人视角**："作者同时报告 Cohen's d + 95% CI + NCV + DCR + ECE，不依赖单一阈值。但当所有指标都指向小效应量时，多指标报告不能改变效应量小的事实。这是在用指标数量掩盖效应量小。"
  3. **R4 的策略是"让审稿人自行判断"**：这是一种诚实策略，但也是被动策略——如果审稿人判断"效应量太小"，多指标报告不能改变结论
- **残余影响**：-1-2%（多指标报告缓解了"单一阈值"问题，但效应量小的事实不变）

### M6: "所有假设都是 exploratory"声明削弱统计推断价值

- **R4 修补**：P0-2 区分 confirmatory/exploratory（E1/E5=confirmatory，E2/E3/E4=exploratory）
- **验证结果**：**部分规避**
- **理由**：
  1. **规避部分**：R4 确实区分了 confirmatory（E1 复现已发表方法）和 exploratory（E3 假设检验），论文明确标注，Discussion 讨论 exploratory 性质
  2. **未规避部分**：
     - **E1 作为 confirmatory 贡献可能被视为"增量贡献"**：复现已发表的 8 种校准方法在跨语料库 ECG 迁移中的表现，这是 confirmatory 工作，但 CBM 审稿人可能认为"复现已发表方法"是增量贡献，不是原创贡献。CBM 期望的是新方法、新发现、新应用——"复现已发表方法在新场景中的表现"可能被视为"应用笔记"而非研究论文
     - **E5 的 confirmatory/exploratory 标记不一致**（见 IC5）：E5 在文档不同位置分别标记为 confirmatory 和 exploratory，这削弱了 confirmatory/exploratory 区分的可信度
     - **confirmatory 部分不包含核心贡献**：核心贡献（Brier reliability 改善）在 E3 中，是 exploratory。confirmatory 部分（E1）只是方法复现。所以论文的"核心贡献"仍然是 exploratory——M6 的核心攻击"统计推断价值削弱"对核心贡献仍然成立
  3. **审稿人视角**："作者区分了 confirmatory（E1 方法复现）和 exploratory（E3 假设检验）。但核心贡献（Brier reliability 改善）在 exploratory 部分。confirmatory 部分只是复现已发表方法——这是增量贡献。论文的核心贡献仍然是 exploratory，统计推断价值有限。"
- **残余影响**：-2-3%（区分有帮助，但核心贡献仍是 exploratory，confirmatory 部分是增量贡献）

### M7: NCV 定义不对称——系统性低估 TS 的临床价值

  2. 新定义对称完整——既考虑 true class 的改对和改错，也考虑 false class 的改对和改错
  3. R4 提供了详细的定义说明，每个分量都有清晰定义
  4. **但引入新攻击 N5**：见 §3 新发现攻击（多类分类中 TN_improved 和 FN_worsened 的操作定义不清晰）

### M8: 备选叙事与 P1-5 修补矛盾——H1 失败后退回被 N6 攻击的叙事

### M9: 假设分层可能被质疑为 cherry-picking——A1 是事后分析计划

- **R4 修补**：P1-8 诚实声明假设分层时间点 + 强调主检验基于理论先验
- **验证结果**：**部分规避**
- **理由**：
  1. **规避部分**：R4 §3.2 E3 诚实披露"假设分层在 A1 修订案中确定，是 post-hoc analysis plan"，同时强调"主检验选择基于 TS 理论性质（不改变 argmax，Brier reliability 是自然主指标）"
  2. **未规避部分**：
     - **"理论先验"推理可能循环**（见 N3）：作者声称"TS 不改变 argmax → Brier reliability 是自然主指标"。但这个推理是事后构建的——作者在看到 ECE 0.016 的结果后，选择 Brier reliability 作为主指标，然后用"TS 不改变 argmax"作为理论依据。这是事后合理化（post-hoc rationalization），不是真正的理论先验
     - **假设分层的 cherry-picking 风险未消除**：即使主检验有"理论先验"依据，次检验和探索性检验的分层仍是在 A1 修订案中确定的。审稿人可能质疑"你怎么知道主检验的选择不是看到部分数据后决定的？"
     - **审稿人视角**："作者说主检验基于理论先验（TS 不改变 argmax）。但这个理论性质在 A1 修订案前就存在——为什么在 A1 修订案中才确定为主检验？如果理论性质是先验的，为什么假设分层是事后的？"
  3. **R4 的"理论先验"论证有一定说服力但不充分**：TS 不改变 argmax 确实是数学性质，但"因此 Brier reliability 是自然主指标"是一个评价选择，不是数学必然——其他校准指标（如 ECE、log loss）也可以作为主指标
- **残余影响**：-1-2%（理论先验论证有帮助，但事后合理化的风险未消除）

## 3. 新发现攻击

### N1: "纯统计贡献"不被临床期刊 CBM 接受——核心贡献与目标期刊不匹配

- **严重性**：严重
- **攻击内容**：R4 将核心贡献重新定位为"Brier reliability 改善作为纯统计贡献"，但目标期刊 CBM（Computers in Biology and Medicine）是临床期刊，审稿人期望临床相关性。纯统计贡献缺乏临床意义，可能被审稿人质疑"这篇论文应该投到统计期刊或机器学习期刊，不是临床期刊"
- **理由**：
  1. **CBM 的定位**：Computers in Biology and Medicine 是"计算机在生物学和医学中的应用"期刊，IF~7，接收率~12%。CBM 审稿人是生物医学 AI 应用研究者，看重临床相关性和实验严谨性
  2. **"纯统计贡献"与 CBM 期望的冲突**：CBM 发表的论文通常有明确的临床应用场景（疾病诊断、治疗方案、临床决策支持）。"Brier reliability 改善作为纯统计贡献"没有直接临床应用——Brier reliability 改善 0.01 对临床决策意味着什么？
  3. **审稿人视角**："作者明确声明核心贡献是'纯统计贡献，不依赖特定临床场景'。但 CBM 是临床期刊——如果贡献不依赖临床场景，为什么投到临床期刊？这篇论文更适合投到 Pattern Recognition 或 IEEE TNNLS（纯技术期刊）。"
  4. **Fallback 期刊的暗示**：R4 声明 Fallback 期刊是 Physiological Measurement（IF~3, SCI Q3/Q2）——这暗示作者知道 CBM 可能不接受"纯统计贡献"，准备了更技术性的 Fallback。但这反过来质疑 CBM 投稿的合理性
- **对接收概率的影响**：-3-5%（CBM 审稿人可能质疑"纯统计贡献"不适合临床期刊，建议改投）

### N2: confirmatory 复现验证是增量贡献，不是原创贡献

- **严重性**：严重
- **攻击内容**：R4 将 E1（复现已发表 8 种校准方法在跨语料库 ECG 迁移中的表现）作为 confirmatory 贡献。但复现已发表方法可能被 CBM 审稿人视为"增量贡献"或"应用笔记"，不是原创研究贡献
- **理由**：
  1. **复现 vs 原创**：CBM 期望的 confirmatory 贡献通常是"在新数据集上验证已有方法"或"比较多种已有方法"——这确实是 confirmatory 工作，但其原创性有限。CBM 更看重新方法、新发现、新应用
  2. **"系统性复现验证"的价值**：R4 声明 E1 是"系统性复现验证已发表方法在新场景中的表现"——这有一定价值（新场景=跨语料库 ECG 迁移），但本质上是"应用已有方法到新数据"，不是方法创新
  3. **CBM 的发表标准**：CBM 发表"方法比较"论文，但通常要求有新的临床洞察或方法改进。纯复现（不改进方法、不发现新现象）可能被视为"benchmark 论文"，接收概率较低
  4. **审稿人视角**："E1 复现了 8 种已发表校准方法在跨语料库 ECG 迁移中的表现。这是 confirmatory 工作，但原创性有限——没有新方法、没有新理论、没有新临床发现。这篇论文的 confirmatory 贡献是什么？只是'已有方法在新数据上的表现'？"
  5. **与核心贡献的脱节**：核心贡献是 Brier reliability 改善（在 E3，exploratory），confirmatory 贡献是方法复现（在 E1）。论文的"核心贡献"是 exploratory，"confirmatory 贡献"是增量——这种结构可能让审稿人困惑"这篇论文的主要贡献到底是什么？"
- **对接收概率的影响**：-2-4%（confirmatory 部分被视为增量贡献，削弱论文的原创性声称）

### N3: Brier reliability 理论先验推理是事后合理化——选择偏差

- **严重性**：严重
- **攻击内容**：R4 声称"TS 不改变 argmax → Brier reliability 是评 TS 效果的自然主指标"作为理论先验依据。但这个推理链条是事后构建的——作者选择 Brier reliability 作为主指标，是因为它是 TS 能改善的指标，然后用"TS 不改变 argmax"作为理论依据。这是指标选择偏差（selection bias in metric choice）
- **理由**：
  1. **推理链条**：TS 不改变 argmax → top-1 accuracy 不变 → 需要一个不依赖 argmax 的指标 → Brier reliability（reliability 分量不依赖 argmax）→ Brier reliability 是自然主指标
  2. **事后合理化**：这个推理链条在逻辑上成立，但问题是：作者为什么选择 Brier reliability 而不是 ECE、log loss、calibration loss？这些指标也不依赖 argmax。作者选择 Brier reliability 是因为 60 实验中 Brier reliability 改善最一致（51/60 支持）——这是数据驱动的选择，不是理论先验
  3. **"理论先验"的虚假性**：如果"TS 不改变 argmax → Brier reliability 是自然主指标"是真正的理论先验，那这个结论应该在实验前就确定。但 R4 自己承认"假设分层在 A1 修订案中确定"——A1 是 9/5 创建的，实验 9/2-9/8 完成。所以"理论先验"是在看到部分实验结果后构建的
  4. **其他合理主指标**：ECE 也是校准指标，不依赖 argmax。log loss 也包含校准信息。为什么 Brier reliability 比 ECE 或 log loss 更"自然"？R4 没有给出比较——只是声明"Brier reliability 是自然主指标"
  5. **审稿人视角**："作者声称 Brier reliability 是'自然主指标'，依据是 TS 不改变 argmax。但 ECE 和 log loss 也不依赖 argmax。为什么选择 Brier reliability 而不是 ECE？是因为 60 实验中 Brier reliability 改善更一致吗？如果是，这是数据驱动的选择，不是理论先验。"
- **对接收概率的影响**：-2-4%（"理论先验"被质疑为事后合理化，削弱 P1-8 修补的可信度）

### N4: "跨方向稳定性分析"只是描述性统计，不是实质性贡献

- **严重性**：严重
- **攻击内容**：R4 将 C2 主贡献定位为"1.9× OOD/ID ratio 的跨方向稳定性分析"。但 1.9× 比率只是一个描述性观察，不是实质性科学贡献——任何跨域研究都可以报告这种比率
- **理由**：
  1. **描述性统计 vs 实质性贡献**：报告"OOD 改善比 ID 改善大 1.9 倍"是一个描述性观察，类似于报告"男生比女生高 1.1 倍"——这是事实，但不是科学贡献。科学贡献需要新方法、新理论、新机制解释
  2. **缺乏机制解释**：R4 报告 1.9× 比率，但没有解释为什么 OOD 改善比 ID 改善大——是因为 OOD 的校准更差所以改善空间更大？还是因为 TS 在 OOD 上有特殊行为？没有机制解释，1.9× 只是数字
  3. **"跨方向稳定性分析"的通用性**：任何跨域研究都可以报告"域 A 改善 vs 域 B 改善"的比率。这不是 ECG 校准研究的独特贡献——任何迁移学习研究都可以做类似分析
  4. **审稿人视角**："C2 主贡献是'跨方向稳定性分析'，报告 1.9× OOD/ID ratio。这只是描述了一个观察结果——OOD 改善比 ID 改善大。这有什么科学价值？任何跨域研究都可以报告这种比率。C2 的实质性贡献是什么？"
  5. **与 M2 的关联**：M2 攻击"诚实披露不是贡献"，R4 用"跨方向稳定性分析"替代。但"跨方向稳定性分析"只是描述性统计，仍然不是实质性贡献——M2 的核心攻击以不同形式成立
- **对接收概率的影响**：-2-3%（C2 主贡献是描述性统计，贡献强度不足以支撑 CBM 接收）

### N5: NCV 对称完整定义在多类分类中操作不清晰

- **严重性**：轻微
- **攻击内容**：R4 的 NCV 对称定义包含 TN_improved 和 FN_worsened，但在 4 类分类（NORM/MI/STTC/CD）中，这些分量的操作定义不清晰
- **理由**：
  1. **TN_improved 的定义**：对 false class c'，TS 前预测 p_c' > τ 但 TS 后 p_c' ≤ τ（从"报告错误类"到"不报告错误类"，且 c' 不是真实标签）→ 改对
  2. **多类分类中的问题**：在 4 类分类中，每个样本有 1 个 true class 和 3 个 false class。对每个 false class，都需要判断 TS 前后 p_c' > τ 的变化。这意味着每个样本贡献最多 3 个 TN_improved 或 FP_worsened——NCV 的分母 N_total 应该是样本数还是样本×类数？
  3. **FN_worsened 的定义**：对 true class c，TS 前预测 p_c > τ 但 TS 后 p_c ≤ τ（从"报告 true class"到"不报告 true class"）→ 改错。但在 4 类分类中，true class 只有 1 个，所以 FN_worsened 的计数清晰
  4. **操作不清晰**：R4 没有明确说明 N_total 是样本数还是样本×类数，也没有说明在多类分类中如何处理 false class 的多个值
- **对接收概率的影响**：-0-1%（定义需要在论文中进一步澄清，但不影响核心逻辑）

### N6: 多指标报告可能导致"信息过载"——审稿人更困惑

- **严重性**：轻微
- **攻击内容**：R4 同时报告 Cohen's d + 95% CI + NCV + DCR + ECE 变化，多指标联合报告可能让审稿人更困惑而非更清晰
- **理由**：
  1. **指标数量**：E3 同时报告 5 个指标（Brier reliability、DCR、NCV、ECE、Cohen's d + 95% CI），每个指标有不同的含义和量纲
  2. **审稿人认知负担**：审稿人需要理解每个指标的含义、判断每个指标的临床意义、综合多个指标得出结论——这增加了认知负担
  3. **"指标购物"风险**：当主指标效应量小时，增加多个辅助指标可能被视为"寻找某个看起来好的指标"——即使 R4 声明"不依赖单一阈值"，多指标报告本身可能被质疑
  4. **审稿人视角**："作者报告了 5 个指标。Brier reliability 改善 0.01，DCR 3%，NCV 1%，ECE 改善 0.016，Cohen's d 0.25。这些指标之间什么关系？哪个最重要？我应该如何综合判断？"
- **对接收概率的影响**：-0-1%（多指标报告是诚实策略，但可能增加审稿人认知负担）

### N7: 10-12 周时间表仍可能不够——E5 OOM 风险

- **严重性**：轻微
- **攻击内容**：R4 将时间表延长到 10-12 周，但 E5（InceptionTime 简化版）可能在 RTX 5060 8GB 上 OOM，需要 fallback 到 ResNet1D 变体，这会增加时间
- **理由**：
  1. **E5 的 OOM 风险**：R4 自己承认"InceptionTime 简化版需实测显存"，如果 OOM，需要 fallback 到 ResNet1D 不同超参变体
  2. **Fallback 的时间成本**：如果 E5 fallback，需要重新设计实验、训练模型、评估结果——这可能增加 1-2 周
  3. **10-12 周的缓冲**：R4 声明"实验阶段 2-3 周，剩余 7-9 周写论文"。如果 E5 fallback 增加 1-2 周，实验阶段变为 3-5 周，剩余 5-7 周写论文——时间仍然紧张
- **对接收概率的影响**：-0-1%（执行风险，不是方案本身的问题）

### N8: 备选叙事隐含退回 N2 增量贡献——"纯统计贡献"失败后只剩 confirmatory 复现

- **严重性**：严重
- **攻击内容**：R4 的备选叙事声明"若 Brier reliability 改善不显著，仍以 Brier reliability 改善作为纯统计贡献，强调 confirmatory 方法复现验证作为独立贡献"。但如果 Brier reliability 改善不显著，"纯统计贡献"是空的，论文只剩"confirmatory 方法复现验证"——这正是 N2 攻击的"增量贡献"
- **理由**：
  1. **备选叙事的逻辑结构**：
     - 如果 E3 成功（Brier reliability 改善显著）→ 核心贡献 = Brier reliability 改善（纯统计贡献）
     - 如果 E3 失败（Brier reliability 改善不显著）→ 核心贡献 = confirmatory 方法复现验证（N2：增量贡献）
  2. **N2 的变体**：备选叙事在 E3 失败时退回"confirmatory 方法复现验证"，但 N2 攻击"复现已发表方法是增量贡献，不是原创贡献"。所以备选叙事隐含退回 N2
  3. **与 M8 的对比**：M8 攻击 R3 备选叙事退回"不确定性感知工作流"（被 N6 攻击）。R4 修改备选叙事不退回"不确定性感知工作流"，但退回"confirmatory 方法复现验证"（被 N2 攻击）——**从一个陷阱跳到另一个陷阱**
  4. **审稿人视角**："如果 Brier reliability 改善不显著，论文的核心贡献是什么？作者说'强调 confirmatory 方法复现验证'——但复现已发表方法是增量贡献。所以如果 E3 失败，这篇论文只是'已有方法在新数据上的 benchmark'？"
- **对接收概率的影响**：-2-3%（备选叙事在 E3 失败时退回增量贡献，削弱论文的稳健性）

### N9: R4 方案过度复杂——12 项修补 + 6 项实验 + 4 贡献重组 + 12 个审稿人问题预防

- **严重性**：轻微
- **攻击内容**：R4 方案包含 12 项修补、6 项实验、4 贡献重组、12 个审稿人问题预防，整体复杂度极高，可能导致执行困难和内部不一致
- **理由**：
  1. **复杂度**：R4 文档 384 行，包含 12 项修补追踪、6 项实验设计、4 贡献重组、多个审稿人问题预防、备选叙事、风险标注——信息密度极高
  2. **内部不一致的风险**：复杂方案更容易出现内部不一致（见 IC1-IC5）。R4 已经出现 E5 同时标记为 confirmatory 和 exploratory 的矛盾（IC5）
  3. **执行困难**：12 项修补需要在论文中同时实施，每项修补可能与其他修补交互——实施过程中容易遗漏或矛盾
  4. **审稿人认知负担**：论文需要同时传达"纯统计贡献 + confirmatory 复现 + 跨方向稳定性分析 + 时间线透明披露 + 多指标报告 + NCV 对称定义 + 假设分层诚实声明"——审稿人可能困惑"这篇论文的核心信息是什么？"
- **对接收概率的影响**：-1-2%（复杂方案增加执行风险和审稿人认知负担）

### N10: "纯统计贡献"叙事自相矛盾——同时声称"纯统计（核心）"和"阈值化决策（辅助）"

- **严重性**：严重
- **攻击内容**：R4 同时声称"核心贡献是 Brier reliability 改善作为纯统计贡献"和"阈值化决策是辅助贡献（适用于多标签、二分类、辅助决策）"。但如果阈值化决策是真实贡献，为什么只是辅助？如果 Brier reliability 是核心，为什么还要报告 DCR 和 NCV？这构成叙事自相矛盾
- **理由**：
  1. **矛盾的结构**：
     - 声称 1：核心贡献 = Brier reliability 改善（纯统计，不依赖临床场景）
     - 声称 2：辅助贡献 = 阈值化决策价值（DCR + NCV，依赖多标签/二分类/辅助决策场景）
     - 矛盾：如果核心贡献不依赖临床场景，为什么还要报告依赖临床场景的辅助贡献？如果辅助贡献有真实价值，为什么只是辅助？
  2. **E3 同时报告两类指标**：E3 同时报告 Brier reliability（纯统计）和 DCR/NCV（临床指标）。如果核心贡献是纯统计，为什么 E3 要报告临床指标？这暗示作者不确定"纯统计贡献"是否足够，所以同时报告临床指标作为保险——这是对冲策略，但构成叙事矛盾
  3. **审稿人视角**："作者说核心贡献是'纯统计贡献'，但 E3 同时报告 DCR 和 NCV（临床指标）。如果纯统计贡献是核心，为什么还要报告临床指标？是因为纯统计贡献不够，需要临床指标补充？那核心贡献到底是什么？"
  4. **对冲策略的代价**：R4 试图用"纯统计贡献 + 临床辅助贡献"的对冲策略规避 M4（核心贡献聚焦到不常见场景）。但对冲策略本身构成矛盾——如果纯统计贡献足够，不需要临床辅助；如果需要临床辅助，纯统计不够核心
- **对接收概率的影响**：-2-3%（叙事自相矛盾，审稿人可能质疑核心贡献的清晰度）

## 4. 内部一致性检查

### IC1: 核心贡献声称"纯统计"但 E3 同时报告临床指标（DCR、NCV）

- **严重性**：严重
- **描述**：R4 §1 声称核心贡献是"Brier reliability 改善作为纯统计贡献（不依赖特定临床场景）"，但 R4 §3.2 E3 同时报告 DCR（阈值化决策改变率）和 NCV（净临床价值）——这两个是临床指标，依赖阈值 τ 和临床决策场景
- **理由**：
  1. **纯统计 vs 临床指标**：Brier reliability 是纯统计指标（不需要阈值、不需要临床决策场景）。DCR 和 NCV 是临床指标（需要阈值 τ=0.5、需要临床决策定义）
  2. **E3 的指标混合**：E3 同时报告 Brier reliability（primary，纯统计）+ DCR（secondary，临床）+ NCV（secondary，临床）+ ECE（exploratory，纯统计）。如果核心贡献是纯统计，为什么 E3 要报告临床指标？
  3. **暗示的不确定性**：这种指标混合暗示作者不确定"纯统计贡献"是否足够说服审稿人，所以同时报告临床指标作为补充——但这与"核心贡献是纯统计"的声称矛盾
- **与 N10 的关联**：IC1 是 N10 的具体表现

### IC2: E1 标记为 confirmatory（复现已发表方法）但包含 LOCO 验证（新分析）

- **严重性**：严重
- **描述**：R4 §3.2 E1 标记为"Confirmatory——系统性复现验证已发表 8 种校准方法"，但 E1 同时包含"LOCO 跨語料庫泛化验证"——LOCO 是新提出的分析，不是复现已发表方法
- **理由**：
  1. **E1 的内容**：E1 包含两部分：(1) L2 shift 矩阵补齐 + 复现已发表 8 种校准方法；(2) LOCO 跨語料庫泛化验证
  2. **confirmatory vs exploratory 混合**：复现已发表方法是 confirmatory，但 LOCO 验证是新分析（没有已发表论文做 LOCO 验证跨语料库 ECG 校准）——LOCO 是 exploratory
  3. **标记不一致**：E1 整体标记为 confirmatory，但包含 exploratory 部分（LOCO）。这削弱了 confirmatory/exploratory 区分的清晰度
  4. **审稿人视角**："E1 标记为 confirmatory，但包含 LOCO 验证——LOCO 是新分析，不是复现。E1 应该标记为'confirmatory + exploratory 混合'？那 confirmatory/exploratory 的区分有什么意义？"

### IC3: C2 主贡献是"post-hoc exploratory observation"——探索性观察能否作为主贡献？

- **严重性**：严重
- **描述**：R4 §4.2 C2 声明主贡献是"1.9× OOD/ID ratio 的跨方向稳定性分析"，但同时标记为"post-hoc exploratory observation, not pre-registered hypothesis confirmation"。探索性观察作为主贡献，与论文的 confirmatory 贡献声称矛盾

### IC5: E5 在文档不同位置分别标记为 confirmatory 和 exploratory——直接矛盾

- **描述**：R4 §3.2 E5 在第一次出现时（约第 216-232 行）标记为"Exploratory——第 3 架构超参变体是新提出的架构"，但在第二次出现时（约第 268-283 行）标记为"Confirmatory——复现 InceptionTime 架构在 ECG 上的表现"。同一实验在同一文档中被标记为不同性质，这是直接矛盾
