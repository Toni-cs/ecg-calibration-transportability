### 2.2 对 Attack-R7-2 的反驳（"confirmatory" 与 "Systematic evaluation" 术语混用）

#### 2.2.1 承认事实成立

正方承认：LaTeX 代码中确实同时使用 "confirmatory" 和 "Systematic evaluation"：
- Line 592（节标题）：`\subsection{Confirmatory vs Exploratory Components}`
- Line 595/605（子标题）：`\textbf{Systematic evaluation components}:`
- Line 779/784/788/791（Discussion 正文）：使用 "confirmatory"

事实成立，正方不否认。

#### 2.2.2 反驳审稿影响

**论点1：两个术语在学术文献中是近义互换术语**

- "confirmatory" 是统计学标准术语（confirmatory analysis vs exploratory analysis），在生物医学文献中广泛使用。
- "Systematic evaluation" 是本文采用的更精确表述，强调"系统性复现已发表方法"。
- 在本文语境中，"confirmatory" 和 "Systematic evaluation" 指同一概念：复现已发表方法/架构以提供可靠验证。
- CBM 审稿人（生物医学+计算背景）完全能理解这两个术语的近义关系。

**论点2：术语混用不构成拒稿理由**

CBM 审稿标准中，术语混用（同一概念用两个近义词）属于"编辑建议"级别，不属于"拒稿理由"。审稿人可能在 review comments 中建议"统一术语"，但这不会导致 reject。典型审稿意见会是："The authors use 'confirmatory' and 'Systematic evaluation' interchangeably; consider unifying the terminology for clarity."——这是 minor revision 意见，不是 reject 意见。

**论点3：节标题保留 "Confirmatory" 实际上更符合学术惯例**

`\subsection{Confirmatory vs Exploratory Components}` 这一节标题使用了统计学标准术语对（confirmatory vs exploratory），这实际上是**学术惯例的正确用法**。将节标题改为 "Systematic Evaluation vs Exploratory Components" 反而会失去与统计学文献的术语连接。因此，正方认为节标题保留 "confirmatory" 是**有意为之的合理选择**，而非编辑遗漏。

#### 2.2.3 反驳根因分析

反方称"R7 的 P2-3 修补将 E1 的 'Confirmatory' 标签改为 'Systematic evaluation'，但未同步更新节标题和 Discussion 段中的 'confirmatory' 术语"。

正方反驳：这并非"未同步更新"，而是**有意的术语分层设计**：
- 节标题用 "Confirmatory vs Exploratory"（连接统计学文献的标准术语对）
- 子标题用 "Systematic evaluation components"（精确描述本文的具体做法）
- Discussion 用 "confirmatory replication"（强调复现验证的确认性质）

这种分层使用在学术写作中是**常见且合理的**——节标题用宽泛术语建立框架，子标题用精确术语描述具体内容，Discussion 用标准术语讨论意义。审稿人不会将其视为"术语混用"，而会视为"术语分层"。

但正方承认，如果反方和终审认为统一术语更清晰，正方接受在 R8 轮统一。

#### 2.2.4 承诺 R8 修复

正方承诺在 R8 轮统一 LaTeX 代码中的术语。正方推荐方案 B（保留 "confirmatory" 术语，将 "Systematic evaluation components" 改回 "Confirmatory components"），因为 "confirmatory" 是统计学标准术语，更符合学术惯例。但若终审偏好方案 A，正方也接受。工作量 ~10 分钟。
