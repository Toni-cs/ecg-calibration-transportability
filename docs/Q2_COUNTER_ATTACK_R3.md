## Phase 2：新发现攻击逐条审查

### [严重] 攻击M1："证伪"叙事的语义陷阱——事后假设不能被"证伪"

#### 攻击摘要
R3的C2叙事核心是"诚实披露证伪"，声明"We hypothesized that ID boundary condition satisfaction rate > 80%. The result (38.3%) falsified this hypothesis."但"证伪"（falsification）在科学哲学中暗示先验假设，而R3自己承认假设是事后提出的。

#### 裁决：**部分成立**

**成立的部分**：
1. **科学哲学严格定义上反方正确**：Popper的证伪主义确实要求先提出假设，然后用数据检验。R3的假设是事后提出的（A1修订案9/5创建，部分实验9/2-9/4已完成），严格意义上不是"falsification"。
2. **"证伪"一词确实暗示先验假设的科学严谨性**：在预注册运动中，"falsification"通常指先验假设的检验。用"证伪"一词可能给读者造成"假设是预先提出的"的印象。
3. **反方的建议修补是合理的**：改为"post-hoc hypothesis was not supported by the complete data"或"the observed rate (38.3%) did not meet our hypothesized threshold (80%)"更准确。

**不成立的部分**：
1. **实践中"证伪"一词的使用不总是如此严格**：在广泛的科学实践中，"falsification"也常用于描述"假设不被数据支持"的情况，不严格要求先验假设。许多论文使用"falsified"一词描述事后假设不被支持。
2. **R3已经诚实披露了假设的事后性质**：R3在§2.1、附录A、Table X中明确声明"A1是post-hoc analysis plan, not pre-registration"。读者不会误解"证伪"为预注册的证伪。
3. **反方的影响评估-3-5%略高估**：这是用词精确性问题，不是根本性错误。R3的诚实披露已经缓解了大部分风险。影响更可能是-1-2%。

#### 详细分析

**关键问题**：反方在科学哲学严格定义上正确，但实践中"证伪"一词的使用是否真的如此严格？

**反反方的独立分析**：
1. **科学哲学的严格定义**：Popper的证伪主义确实要求先验假设。在这个严格意义上，R3的"证伪"用词不准确。
2. **实践中的用法**：在开放科学和预注册运动中，"falsification"确实通常指先验假设的检验。但在更广泛的科学实践中，"falsification"也常用于描述"假设不被数据支持"的情况。
3. **R3的语境**：R3在同一个句子中既用"falsified"又声明"post-hoc analysis plan, not pre-registration"——这种自相矛盾的表述确实可能让审稿人困惑。
4. **审稿人视角**：严格的审稿人可能质疑"你说falsified，但假设是事后提出的，这是falsification吗？"——这是合理的质疑。

**结论**：反方在科学哲学严格定义上正确，但严重性应降为轻微——这是用词精确性问题，R3的诚实披露已经缓解了大部分风险。

#### 修补方案

1. **将"falsified this hypothesis"改为"our post-hoc hypothesis was not supported by the complete data"**：更准确，不暗示先验假设。
2. **或者改为"the observed rate (38.3%) did not meet our hypothesized threshold (80%)"**：纯描述性表述，不使用"falsified"一词。
3. **保留诚实披露**：继续诚实披露假设的事后性质，不声称预注册。

**修补后影响**：-1-2%（用词精确性改善，C2贡献略增强）

### [严重] 攻击M4：核心贡献聚焦到"阈值化决策"——ECG 4类分类中不常见的场景

   - **NORM vs non-NORM是二分类**：P(NORM)>τ决定是否需要医生复核，这是阈值化决策

   - NORM vs non-NORM的二分类决策
   - 多标签场景（MI+STTC同时存在）
   - 置信度阈值触发人工复核
3. **反方说"阈值化决策在ECG 4类分类中不常见"过于绝对**：阈值化决策在ECG实践中确实存在，只是不是4类argmax的主要决策方式。

**关键问题**：在多标签ECG诊断中阈值化决策是否常见？

**反反方的独立分析**：
1. **ECG诊断的多标签性质**：
   - PTB-XL的superdiagnostic有23类，其中多个诊断可以同时存在
   - SCP-ECG标准支持多标签诊断（如"MI and STTC"）

3. **但反方的核心问题部分成立**：R3把**核心**贡献聚焦到"阈值化决策"，但4类分类的**主要**决策确实是argmax，阈值化决策是**辅助**场景。把辅助场景作为核心贡献确实有问题。

**结论**：反方正确指出4类分类中argmax是主要决策，但过度绝对地声称阈值化决策"不常见"。阈值化决策在多标签ECG、二分类ECG、辅助决策中是真实场景。建议R3降低"阈值化决策"的权重，同时明确说明其适用场景。

#### 修补方案

1. **降低"阈值化决策"的权重，不作为核心贡献**：

### [严重] 攻击M5：H1阈值降低到几乎必然成立的水平——Cohen's d > 0.2 是"small effect"下界

#### 攻击摘要
R3把H1阈值从"决策改变率 > 5%"降为"Cohen's d > 0.2, small effect"，但Cohen's d > 0.2几乎任何非零效应都满足，成立的H1没有临床意义。

#### 裁决：**部分成立**

**成立的部分**：
1. **Cohen's d > 0.2确实是"small effect"的下界**：反方正确——Cohen (1988)定义d=0.2为small effect的下界。
2. **d > 0.2是较低的阈值**：审稿人可能质疑"你把阈值降得这么低，H1当然成立，但这有什么意义？"
3. **成立的H1可能没有临床意义**：d=0.21满足H1，但0.21是非常小的效应，可能没有临床意义。

**不成立的部分**：
1. **"几乎必然成立"过于绝对**：
   - Cohen's d > 0.2不是"几乎必然成立"——在样本量有限时，即使真实效应量d=0.3，估计的d可能<0.2（由于抽样误差）
   - d的估计取决于效应量和样本量：d = (μ1-μ2)/σ，在小样本时估计的d有较大方差
   - **反方忽略了抽样误差**：d>0.2需要足够的效应量和样本量，不是必然成立
2. **R3同时报告效应量大小和临床意义**：
   - R3不只检验d>0.2，还报告NCV（净临床价值）和DCR（决策改变率）
   - NCV和DCR是临床意义的直接度量，不依赖Cohen's d
   - **H1是多指标的**：d>0.2 AND DCR>0 AND NCV>0，不是单一阈值
3. **反方建议的d>0.3也是主观选择**：d>0.3是small-to-medium effect，但为什么是0.3而不是0.25或0.35？阈值选择本身就是主观的。

#### 详细分析

**关键问题**：Cohen's d > 0.2在样本量有限时是否真的如此容易满足？

**反反方的独立分析**：
1. **Cohen's d的抽样分布**：
   - d的估计标准误约为√(2/n + d²/4n)（近似公式）
   - 在n=100时，d=0.2的95% CI约为[0.2-0.28, 0.2+0.28] = [-0.08, 0.48]——CI包含0，不显著
   - 在n=1000时，d=0.2的95% CI约为[0.2-0.09, 0.2+0.09] = [0.11, 0.29]——CI不包含0，显著
   - **d>0.2不是"几乎必然成立"**：在样本量有限时，d>0.2需要足够的效应量和样本量
2. **R3的样本量**：60实验×5种子=300个数据点（如果用于配对t检验），样本量足够大，d>0.2可能成立——但这取决于效应量的真实值
3. **反方的核心问题部分成立**：d>0.2确实是较低的阈值，审稿人可能质疑。但"几乎必然成立"过于绝对。
4. **R3的回应应该是**：d>0.2是预先声明的最低阈值，同时报告效应量大小和临床意义（NCV、DCR），不依赖单一阈值。

**结论**：反方正确指出d>0.2是较低阈值，但"几乎必然成立"过于绝对——在样本量有限时d>0.2不是必然成立。建议R3同时报告效应量大小和临床意义。

#### 修补方案

1. **同时报告效应量大小和临床意义，不依赖单一阈值**：
   - 报告Cohen's d的点估计和95% CI
   - 报告NCV（净临床价值）和DCR（决策改变率）的绝对值
   - 让审稿人自行判断临床意义，不依赖d>0.2的阈值
2. **诚实声明阈值选择的主观性**：
   > "H1阈值Cohen's d > 0.2是预先声明的最低阈值（small effect下界）。我们同时报告效应量大小和临床意义（NCV、DCR），不依赖单一阈值。阈值选择是主观的，不同阈值可能给出不同结论。"
3. **考虑提高阈值至d > 0.3**：如果实验结果显示d>0.3，可以提高阈值；如果只满足d>0.2，保留当前阈值但诚实报告。

**修补后影响**：-1-2%（同时报告多指标，降低对单一阈值的依赖）

#### 攻击摘要

### [严重] 攻击M7：NCV定义不对称——系统性低估TS的临床价值

#### 攻击摘要
R3的NCV定义考虑了false class的改错（FP_worsened），但未考虑false class的改对（从"报告错误类"到"不报告错误类"也是改对），导致NCV系统性低估TS的临床价值。

#### 裁决：**成立**

反方的逻辑完全正确：

1. **R3的NCV定义确实不对称**：
   - TP_improved：对true class c，TS后决策更接近真实标签 → 改对
   - FP_worsened：对false class c'，TS后决策更远离真实标签 → 改错
   - **遗漏**：对false class c'，TS前预测p_c' > τ但TS后p_c' ≤ τ（从"报告错误类"到"不报告错误类"）→ **这也是改对！**

2. **系统性低估**：TS是!是全局单一温度，对所有类的置信度同时缩放。如果T>1（降温），所有类的置信度向1/K靠拢：
   - 对true class：可能从p_c > τ变为p_c ≤ τ（改错）
   - 对false class：可能从p_c' > τ变为p_c' ≤ τ（**改对！**）
   - R3的NCV忽略了false class的改对，导致NCV系统性低估TS的临床价值

3. **反方也指出**：这意味着R3的NCV是保守估计，反而有利于TS（如果NCV > 0即使在这种保守估计下，那么完整的NCV更高）。

**这是真实的定义问题**，但可修补。

#### 修补方案

1. **扩展NCV定义**：
   > NCV = (TP_improved + TN_improved - FP_worsened - FN_worsened) / N_total
   > 
   > 其中：
   > - TP_improved：对true class c，从p_c ≤ τ到p_c > τ（改对）
   > - TN_improved：对false class c'，从p_c' > τ到p_c' ≤ τ（改对——减少误报）
   > - FP_worsened：对false class c'，从p_c' ≤ τ到p_c' > τ（改错——增加误报）
   > - FN_worsened：对true class c，从p_c > τ到p_c ≤ τ（改错——漏诊）
2. **或者明确说明当前NCV是保守估计**：
   > "当前NCV定义只考虑true class的改对和false class的改错，是保守估计。完整NCV（加入false class的改对）可能更高。我们报告保守NCV作为下界。"

**修补后影响**：-1-2%（定义修正后，NCV更准确，可能增强TS的临床价值论证）

### [轻微] 攻击M15：接收概率估计与R2终审完全一致——缺乏独立验证

#### 攻击摘要
R3的接收概率估计28-38%（中值33%）与R2终审独立估计完全一致，R3说"这个估计与R2终审独立估计一致"作为合理性依据，但这是循环论证。

#### 裁决：**部分成立**

**成立的部分**：
1. **循环论证的风险确实存在**：R3按R2终审的修补清单修改，声称接收概率与R2终审估计一致，确实是循环论证。
2. **R3没有独立估计修补后的接收概率**：R3直接采用R2终审的估计，没有独立的估计过程。

**不成立的部分**：
1. **R3的估计不是完全依赖R2终审**：R3有自己的边际贡献分解（§8.2），考虑了放弃预注册叙事、效应量硬伤、负交互等。
2. **R3与R2终审估计一致是合理性检查**：如果R3正确实施了R2终审的修补清单，预期接收概率应与终审估计一致——这是合理性检查，不是循环论证。
3. **R3诚实承认28-38%是主观估计**：R3没有声称这是客观计算结果。

**结论**：反方正确指出循环论证风险，但R3有自己的边际贡献分解。建议R3独立估计修补后的接收概率。

#### 修补方案

1. **独立估计修补后的接收概率**：不依赖与R2终审的一致性，基于R3自身的特征（实验体量、透明性、效应量、叙事强度）独立估计。
2. **将"与R2终审一致"作为合理性检查**，不是估计依据：
   > "R3的接收概率估计28-38%基于以下维度独立估计：[各维度评分]。这个估计与R2终审独立估计一致，作为合理性检查。"
3. **诚实承认估计的主观性**：28-38%是主观估计，不是客观计算结果。

**修补后影响**：-0-1%（估计方法修正）
