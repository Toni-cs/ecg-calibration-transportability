## 0. 三句话结论

1. **仓库里不存在新算法，也不该硬造一个。** 四个"原创组件"经逐行核对都是标准复现/组合（Shapley 1953、King–Zeng 2001、平衡分解框架、Fisher 信息行列式）。在 CMPB 造一个未经真实数据验证的新算法，是**负资产**。
2. **真正的强化点不在"加算法"，而在"把已经躺在仓库里、却没写进论文的验证结果写进去"。** 本轮已跑出两个可直接入稿的硬结果：真实数据无标签先验恢复（BBSE 40.9% 相对改善）+ 噪声底机理判别检验。
3. **主发现（ΔECE_OOD = +0.0159）经对抗审查后存活**，但只能用**排除性**措辞，不能用确证性措辞。

## 1. 新算法问题：终审裁定

**结论：不新增算法。** 依据（已逐行核对源码）：

| 组件 | 位置 | 实质 |
|---|---|---|
| 三成分分解 | `src/utils/decomposition.py` | Shapley (1953) + 既有 prevalence/slope/intercept 框架的**标准组合** |
| `recover_slope_intercept` | 同上 L100 | 教科书式反演 `ŝ=1/a, b̂=−c/a` + King–Zeng (2001) 病例对照校正 |
| BBSE / EM | `src/utils/prior_shift.py` | Lipton et al. (ICML 2018) / Saerens et al. (2002) 的**标准重实现** |
| `fisher_information_det` | 同上 L139 | 教科书 Fisher 信息行列式 |

**为什么不造**：Pro 代理自己承认的"最强主张"是——*"最关键的一步是把 decomposition estimator 的真实数据 cross-fitting 做完并修好幅度偏差，那是唯一能把这篇从'用方法'推成'给方法'的东西。"* 但同一份真实数据显示该估计器平均误差 **+0.29**（mean `delta_pred` − `delta_obs_orig` = **+0.2856**，
median **+0.2913**，n=60；来源 `results/strengthening_battle_corrected.json`，**不是**
`results/c3_crossfit_results.csv` —— 后者是 8 种标定法 × 2 架构的 LOO-R² 表，其 `0.29x` 字样
只是 `decay_mean`/`ci_hi` 的巧合数字。此归属错误由第三轮对抗审查 R3-B 指出并已更正），
是目标效应量 0.0159 的 **18 倍**。在误差比效应大 18 倍的估计器上包装"新算法"，是把已知硬伤放进标题。

**唯一合理的"准新方法"路径**（若日后确需）：把 BBSE 真正接进 `decompose_benefit` 的 `prev_hat` 路径（现在 `decomposition.py:336-343` 仍是设计常量回读），使 prevalence 腿从"设计常量"升级为"无标签估计"。但**必须先解决下节的能力不足问题**，否则新瓶装旧酒。

## 2. 待写入论文的两个新结果（本轮产出）

### 2.1 真实数据无标签先验恢复（BBSE/EM）

- **脚本**：`scripts/real_prior_recovery.py`
- **数据**：`results/real_prior_recovery.csv`（60 个官方 cell，剔除 2 个 BiMamba toy cell）+ `real_prior_recovery_summary.json`
- **协议**：target 域标签**仅用于评分**，估计器全程无标签

| 指标 | 值 |
|---|---|
| 朴素基线误差 | 0.1916 |
| BBSE 误差 | **0.1132** |
| EM 误差 | 0.1923（基本无用） |
| BBSE 优于基线 | **56/60** |
| 相对误差下降 | **40.9%** |
| pair 级聚类 bootstrap (B=10000) | **Δ = +0.0784 [+0.0486, +0.1107]** |
| 方向一致 | **6/6** |
| 留一法（drop 任一 pair）CI 下界 | 仍 ≥ +0.0436 |

**必须一并披露的反例**：4/60 cell BBSE 反超朴素基线（如 `chapman_cpsc_inceptiontime_seed42`: 0.306 vs 0.168）；5/60 cond>1e3；1/60 cond≈3.2e4 已逼近奇异。

**写作口径**：`boundary-sensitive`，**不得**写成 "diagnostic-usable"。

### 2.2 噪声底机理判别检验（本轮最重要的方法论补充）

**这是本轮对抗审查的最大收获。** Con 代理提出的致命攻击是：主效应 +0.0159 小于 T≥2 时的噪声底（0.095–0.164），而实测拟合温度中位数 1.836、50% 的 cell T≥2，因此主发现可能是度量噪声。

我实测：**75% 的 cell 满足 `floor_hi(T) ≥ 0.0159`（危险区）**——攻击的适用面确实很大。

**判别结果（`scripts/adjudicate_noise_corrected.py`）**：

| 证据 | 结果 | 效力 |
|---|---|---|
| 斜率 β̂（ΔECE~T） | **+0.00155**，置换 95%CI [−0.00372, +0.00385] | 有效 |
| 拒绝 H0: β=+0.045（底噪机理值） | p < 1e-4，相差 **29 倍** | 有效 |
| 跨 T 分层 | T<1.25: **+0.0174** vs T≥2.2: **+0.0155**（不随 T 增长） | 有效 |
| 消融负对照 | 同族 SmoothECE 在 target test 上为 **−0.1001**（可变号） | 有效 |
| 逐 cell 扣底噪 | **−0.0468** | **无效，禁止写入** |

**关于最后一行**：扣底噪法把一个已知为正的配对量拖到显著负，是**校正量量纲错误**导致的伪结果——底噪定义域是完美校准（ECE_raw≈0.017），真实 cell 的 ECE_raw 是 0.036–0.469。且逐 cell CI 宽度中位仅 0.0011，比底噪小 1–2 个数量级，说明底噪并未以确定性加性偏差形式进入主终点。**blue 代理的隐藏假设 #3 在此被实测证实。**

**终审措辞**（可直接入稿，排除性而非确证性）：

> ΔECE_OOD 随拟合温度 T 的斜率（+0.0016, permutation 95% CI [−0.0037, +0.0039]）比 SmoothECE 噪声底所预测的斜率（+0.04~0.05）小一个数量级以上，且在按 T 分层后效应量不随 T 增长；因此该正向效应不能由温度相关的度量噪声底解释。但鉴于噪声底本身基于理想化置信分布估计、且部分分层样本量偏小（n<10），此结论应视为**排除性证据而非确证性因果判定**。

## 4. 只加一件事：选哪个

三个代理独立收敛到**同一个**答案：

> **把 2.2 的噪声底机理判别检验作为独立新节（"Noise-floor mechanism test"）写入论文，而不是继续引用旧噪声底段落的定性论证。**

**理由**：CMPB 是方法学期刊，审稿人第一刀必然砍在"你的效应量小于你自己报告的度量噪声底"。现有的 §noise_floor 只做定性辩护（"方向相反故不构成解释"），**方向论证已被证明无效**（主发现与底噪同向）。机理判别检验把辩护从**防守转为主动**——用斜率量级 + 分层不变性 + 负对照三重证据直接排除机理，边际成本约一个脚本（已完成）。

**预期收益**：一次性堵死最可能导致 desk reject / major revision 的攻击面。

## 6. 诚实底线（勿越界）

- 本文**没有**新算法。写作时不得暗示有。
- BBSE **没有**修复 decomposition 估计器——两者估计目标不同（π_target vs 效应归因系数 s,b），是**外挂验证**，是"换轨了，没修轨"。论文中不得混淆。
- decomposition 估计器真实数据误差 +0.29，是效应量的 **18 倍**。这是本文**真实短板**，必须写明，不得淡化。
- 主发现的辩护是**排除性**的，不是确证性的。
